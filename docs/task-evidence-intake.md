# Task Evidence Intake

Evidence intake is draft based.

1. The contributor creates an evidence bundle.
2. The contributor adds text, URL snapshots, uploads, artifact references, or automation reports.
3. Cerbanimo validates type, ownership, visibility, MIME, SSRF, and size policy on the server.
4. Preview freezes requirements, validation policy, reflection, item digests, and manifest v2.
5. Confirmation starts the validation run.

Draft mutation is limited to the owning actor. Project owners, reviewers, and admins may inspect according to policy, but ordinary contributor routes cannot silently edit another contributor's draft.

Superseding creates a new draft linked to the old bundle. The old bundle remains immutable and auditable.
